## Gap fill (comparison with the LymeStarter Angular wrapper)

Compared `mikedown-editor.component.ts`, `angular-mikedown-host.ts` and its spec (read only). Tests: lint 0 errors, compile ok, test:unit 1540 passed, test:edge 22, test:packages 17.

Ported, each with a test in `packages/core/test/binding.test.ts`:

- **No report for unchanged text.** The wrapper skips `onChange` when the pending markdown equals the last value (type then undo within the debounce). The binding now does the same.
- **External write while a keystroke is pending.** The wrapper cancels the pending report, then skips the reload when the editor already shows that text (keeps the caret). The binding used to reload whenever something was pending; it now cancels, records the value, and skips the reload when equal.
- **Read-only and disabled.** Added `readOnly` / `disabled` options and `setReadOnly()` / `setDisabled()`; the editor is read-only when either is set.
- **Touched.** The wrapper flushes and calls touched on `focusout` when focus leaves the whole control, ignoring moves inside it and into `.mikedown-portal`. Added `onTouched` with the same rule (the editor-blur flush stays too).
- **Destroy.** Order (flush, stop observers, destroy handle) already matched; a test now covers it, including no callbacks after destroy.

Deliberate differences, not ported:

- Theme: the wrapper watches only `data-mode` on `<html>` and passes `'auto'` to core when absent. The binding follows the decisions doc (`closest(darkSelector)`, attribute filter derived from the selector) and resolves `auto` to light or dark itself, with a `prefers-color-scheme` listener.
- Wrapper-only concerns left to M8: Angular zone handling, the `ready` output (use `binding.handle.on('ready')`), localStorage settings load/save, form-field default settings (width 100%, Roboto, 15px), `minHeight`, image upload and src resolver host, router link handling, placeholder via CSS variable (core `placeholder` replaces it).
- `features` and `hostOwnsShortcuts` are plain core options, passed through.
