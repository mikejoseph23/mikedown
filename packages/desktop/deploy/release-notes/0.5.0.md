- Tables: pasting a markdown pipe table or tab-separated text makes a table, and pasting a spreadsheet range into a table fills the cells instead of nesting a table.
- Tables: copying cells puts a markdown table on the clipboard, and Copy Table as Markdown is in the right-click menu.
- Tables: new shortcuts to add a row below (Cmd+Enter) or above (Cmd+Shift+Enter) and to delete a row (Cmd+Option+Backspace), plus Move Row and Move Column in the right-click menu.
- Tables: the size picker works from the keyboard, a + at the table's edge adds a row or column, and the drag handles are easier to see and follow the table.
- Tables: a new Align table columns setting lines up the pipes in the saved markdown (off by default).
- Fixed: Backspace in a table cell no longer empties the whole cell, and a `|` in code or a link inside a cell no longer splits it.
- Removed Toggle header row and Merge cells, which saved tables that reopened as raw HTML.
