- Chat with AI (experimental, off by default): turn on AI features, then choose **Chat** from the AI menu. The panel answers about this document or, with the Active bases scope, from your documentation bases: folders of markdown files read from disk, set up on the Documentation bases page in Settings. Answers have numbered citations that open their sections and can be inserted at the cursor. Each base has its own cloud switch, off by default.
- AI Activity panel (experimental, off by default): turn on AI features, then the `mikedown.ai.activityPanel` setting, and open **AI Activity…** from the AI menu or the AI tab of Settings to see each AI request of this session with the exact messages sent and the raw response. It is kept in memory only, can be copied or saved to a text file, and is cleared when you turn the setting off.
- Inline suggestions (experimental, off by default): turn on AI features, then **Inline suggestions** on the AI tab of Settings, and dim continuation text appears when you pause while writing. Tab accepts it, Cmd/Ctrl+Right accepts one word, Escape dismisses it, and Cmd/Ctrl+Alt+Space asks on demand. **Local engines only** starts on; with it off, each request sends the text around the cursor to the engine, after the usual consent prompt. Accepted suggestions are listed in AI Activity. The AI menu has an **Inline suggestions** row that turns the feature on or off at once.
- An AI command or shortcut for a feature that is switched off now says so instead of doing nothing.
- Edit Link updates the link when only the cursor is in it, and level 6 headings look like a smaller level 5 heading (#12).
- Primary and danger buttons keep their colors on hover.
- A bare URL at the end of a file's first block is no longer turned into a link when the file loads.
