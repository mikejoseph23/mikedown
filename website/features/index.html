Which MikeDown?

Desktop is a free app for a folder of notes, the VS Code extension opens markdown in your editor tabs, and the web component and React, Vue and Angular packages put the editor in a web app you build. Here is every feature, edition by edition.

Notes

  1. AI writing tools are experimental and off by default in both apps; nothing is sent until you set up an engine. What is sent, and where.
  2. In VS Code, the file tree, tabs, split editors, folder search, version history (Git, Timeline), multiple windows and updates come from VS Code itself, not from the extension.
  3. MikeDown Desktop updates itself on macOS and Windows; the Linux AppImage does not.
  4. Host must provide: the editor has the hook and your app supplies the piece (a host method, an AI host, a dictionary URL, storage). See Bring your own AI and Toolbar layout on the Developers hub.
