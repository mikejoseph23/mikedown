MikeDown for Angular

A WYSIWYG markdown form control for Angular 17 and later. It works with reactive forms and ngModel, and loading a value never marks the control dirty.

npm install @mikedown/angular @mikedown/core mermaid

The code on this page

This standalone component is the editor above, bound to a FormControl. The page loads it in an @defer block and passes theme and readOnly from the controls.

Install mermaid even though diagrams load lazily: the Angular builder resolves the import at build time.

Framework notes

Standalone components

Import MikeDownEditorComponent and use <mikedown-editor> with formControlName, [formControl] or [(ngModel)]. Pair inputId with a <label for> to name it.

<label for="notes">Notes</label>
<mikedown-editor formControlName="notes" inputId="notes" />

Validators.required treats an empty editor as invalid, and control.disable() makes it read-only.

NgModule apps

Import MikeDownModule into the feature module that uses the editor, so the editor stays in that feature's lazy chunk.

@NgModule({
  imports: [ReactiveFormsModule, MikeDownModule],
  declarations: [NoteFormComponent],
})
export class NotesModule {}

angular.json

Add the editor stylesheet to styles. For spell check, copy core's dictionaries into your assets and pass their folder as spellcheckDictionaryUrl.

"styles": ["node_modules/@mikedown/core/dist/styles.css", "src/styles.css"]

Versions, lazy loading and dark mode

Angular 17 to 22 are supported. The editor is large, so put it behind a lazy route or @defer. darkSelector="html[data-mode=dark]" or ".dark-theme" makes theme="auto" follow your app's dark mode.
