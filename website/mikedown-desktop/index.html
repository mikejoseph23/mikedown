MikeDown Desktop

A free WYSIWYG markdown editor for macOS and Windows, with a Linux preview. Double-click a .md file, or open a folder of notes, and write.

Download for Mac macOS 12 Monterey or later, Apple silicon and Intel Download for Windows Windows 10 version 1809 or later

Signed and notarized on macOS, signed on Windows. Updates install from inside the app.

Download for Linux (preview) · x86_64 AppImage, @@LINUX_MB@@ MB Unsigned, no auto-update. Run chmod +x on it first. On Arch it needs fuse2, or launch it with --appimage-extract-and-run.

What's inside

Everything works on plain .md files in folders you already have. Nothing to import, and no account.

Writing

Write in a formatted view that reads like the finished document and saves plain markdown. Press Cmd+/ (Ctrl+/ on Windows) to see and edit the source whenever you want it.

  • Tables, callouts, math and Mermaid diagrams
  • Emoji, footnotes and slash commands
  • Find and replace, and spellcheck with dictionaries included
  • An outline, properties and backlinks beside each document
  • Wikilinks and tags across the folder
  • Light and dark, following your system

Files and folders

Open one file, or a whole folder of notes. The files stay ordinary .md text on your disk, so other apps, Git and sync tools keep working with them.

  • A file tree and tabs
  • Split panes, each with its own tabs and sidebar
  • Search across the folder, with match case and whole word options
  • Paste or drop an image and it is saved in an images folder next to the note
  • Notices when another app changes an open file
  • Unsaved changes are backed up as you type and come back on the next launch

Version history

MikeDown keeps a snapshot on every save in an open folder, in .mikedown/versions/ inside that folder. Compare any snapshot with the current text and go back to it if you need to.

  • Side-by-side diff against the current version
  • One-click restore
  • Keeps the newest 25 snapshots of each file by default
  • Skips files above a size limit you can change

Export

When a note has to leave your folder, export it to HTML, print it or save it as PDF.

  • Standalone HTML, with images embedded or copied to a folder beside it
  • Print, or save as PDF from the system print dialog

Multi-window

Give each folder its own window and open as many as you like. Files land where they belong.

  • New Window from the File menu, the Dock icon's menu on macOS or the taskbar's right-click menu on Windows
  • Open Containing Folder on a file from outside the open folder opens that folder in its own window
  • A file you open from Finder or Explorer goes to the window that already has its folder

How the AI tools work

AI writing tools

Experimental

Optional help with the text in front of you, from an engine you choose: a model on your own machine, or a cloud provider you allow.

What it does

Select some text and ask for a rewrite: shorter or longer, more formal or casual, or for a different audience. Or have it explain, translate or summarize, or suggest a title and properties for the document. Every AI edit is one undo step.

Off until you turn it on

AI is off by default. Nothing is sent anywhere until you set up an engine, and the setup starts only when you ask for it, from the AI button in the toolbar or from Settings.

Local first

MikeDown finds a local server you already run (oMLX, LM Studio, Ollama and others) and sets it up in one click. A local engine keeps everything on your machine or your network.

Cloud, if you opt in

Anthropic, OpenAI and other providers are available after you turn on cloud engines. The first request in a folder asks you first and says what it sends. API keys stay in your system keychain, and each provider's policy is linked where you add the engine.

Install

Mac

  • Open the .dmg and drag MikeDown to Applications.
  • Requires macOS 12 Monterey or later.

Windows

  • Run the installer. It installs for your user account, no administrator needed.
  • Requires Windows 10 version 1809 or later. The Microsoft Edge WebView2 runtime is installed if missing.

Linux (preview)

  • Download the AppImage, make it executable (chmod +x MikeDown-*.AppImage) and run it.
  • x86_64 only. Unsigned, and it does not update itself: download new versions from this page.
  • Needs FUSE 2 (fuse2 on Arch, libfuse2 on Debian and Ubuntu). Without it, run ./MikeDown-*.AppImage --appimage-extract-and-run.

Privacy

MikeDown Desktop has no telemetry, no analytics and no account. Your documents stay on your computer unless you set up a cloud AI engine.

AI features (experimental) are off by default and send nothing until you set up an engine. A local engine (oMLX, LM Studio, Ollama and others) keeps everything on your machine or your network. A cloud engine is used only after you turn on cloud engines and allow it for a folder; then the text you ask about is sent to that provider under its API terms. Each provider's policy is linked where you add the engine. API keys stay in your system keychain.

The only network request the app makes on its own is the update check: shortly after launch and then every few hours it downloads a small update file (for example latest-darwin-aarch64.json, or latest.json) from this site to see whether a newer version exists. You can turn it off in Settings > App (Automatically check for updates). Links you click open in your browser, and images in your documents that point at web addresses load from those addresses.

This page sets no cookies and loads no tracking scripts.
