MikeDown for React

A WYSIWYG markdown editor component for React 18 and 19. Use it like an input: pass value and onChange, and the editor reports markdown 150 ms after the last keystroke.

npm install @mikedown/react @mikedown/core

The code on this page

This file is the editor above. The page renders <Demo> and passes theme and readOnly from the controls.

The editor fills its container, so give it a height with className or style. Import the stylesheet once in your app.

Framework notes

Next.js app router

The package entry starts with 'use client', so a Server Component can import it. Keep the state in a small client component and pass the initial markdown down from the server.

// app/notes/editor.tsx
'use client';

import { useState } from 'react';
import { MikeDownEditor } from '@mikedown/react';
import '@mikedown/core/styles.css';

export function NotesEditor({ initial }: { initial: string }) {
  const [md, setMd] = useState(initial);
  return <MikeDownEditor value={md} onChange={setMd} aria-label="Notes" style={{ height: 480 }} />;
}

Load it later

The editor is large. To keep it out of the first bundle, load it with next/dynamic (or React.lazy on Vite).

const MikeDownEditor = dynamic(
  () => import('@mikedown/react').then((m) => m.MikeDownEditor),
  { ssr: false },
);

Server rendering is safe without it: nothing touches the DOM at import or render, and the editor appears after hydration.

Vite and StrictMode

Vite needs no plugin or config. The editor is created in an effect and destroyed on cleanup, so StrictMode's double mount is fine, and unmounting flushes a pending change to onChange.

Svelte, Solid or Preact?

Use the web component. It works anywhere custom elements do, and submits with forms.
