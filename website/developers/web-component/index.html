The MikeDown web component

<mikedown-editor> is a markdown editor that behaves like a <textarea>: it submits under its name, honors required, and resets with the form. Use it on plain pages, in server templates, or in any framework without its own MikeDown package.

npm install @mikedown/web-component @mikedown/core

Use a CDN insteadREADMEnpm

The code on this page

A plain <form> wraps the editor and a <textarea>. The textarea is the field until the script loads; then the editor takes over its text, name and required. Clear the editor and press Submit to see the browser's own validation.

The page puts this markup on the stage, runs the script, and sets the element's theme and readOnly properties from the controls.

From a CDN, with no build step

One module script loads a self-contained bundle (the editor, its dependencies and its CSS) and defines <mikedown-editor>. Pin the version; never use @latest.

KaTeX and Mermaid load from jsDelivr the first time a document uses math or a diagram. Turn either off with features='{"math":false}'.

Framework notes

Svelte

Svelte renders custom elements directly. Pass the value as a property and listen for change.

<mikedown-editor value={body} on:change={(e) => (body = e.detail.value)}></mikedown-editor>

Lit

Bind objects such as host and settings as properties.

<mikedown-editor .value=${this.body} @change=${(e) => (this.body = e.detail.value)}></mikedown-editor>

htmx

change bubbles, so a form can save as the user types. htmx reads the form with FormData, which includes the editor's value.

<form hx-post="/notes/42" hx-trigger="change delay:500ms" hx-swap="none">
  <mikedown-editor name="body" value="# Notes"></mikedown-editor>
</form>

Rails, Django, Razor, Laravel

Wrap the textarea your template already renders. Without JavaScript it stays a textarea; with it, the editor takes over and submits the same field once.

<mikedown-editor>{{ form.body }}</mikedown-editor>
