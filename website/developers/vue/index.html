MikeDown for Vue

A WYSIWYG markdown editor component for Vue 3.3 and later. Bind it with v-model; it updates the model 150 ms after the last keystroke and at once when focus leaves.

npm install @mikedown/vue @mikedown/core

The code on this page

This single-file component is the editor above. The page mounts it and passes theme and readOnly from the controls.

Give the editor a height with CSS on the component: class and style land on its container.

Framework notes

Nuxt

The editor needs the DOM, so render it on the client only.

<template>
  <ClientOnly>
    <MikeDownEditor v-model="md" />
  </ClientOnly>
</template>

If the server render complains about the stylesheet import, add @mikedown/core and @mikedown/vue to build.transpile.

Register it once

Use the plugin to make <MikeDownEditor> available in every template.

import { createApp } from 'vue';
import MikeDown from '@mikedown/vue';

createApp(App).use(MikeDown).mount('#app');

Reaching the editor

A template ref exposes handle, the editor handle, for commands such as handle.command('toggleBold'). It is null until the component mounts.

Vue 3.3 and later

The component declares its props and emits explicitly instead of using defineModel, so it works on Vue 3.3. On Svelte or another framework, use the web component.
