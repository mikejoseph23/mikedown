# Getting started

Welcome to Acme. This page covers the first week.

## Accounts

Ask your manager for a directory account. Sign in once with the temporary password, then set your own. Accounts expire after 90 days of no sign-in.

## Access

Request repository access in the access tracker. Read access is granted the same day; write access needs a manager's approval.

## Where things live

The team handbook is kept outside this folder, see [the handbook](../handbook.md). Security rules are in [Security](security.md).
